# quant-learning

写嵌入式 C 写了好几年，最近想搞清楚量化交易到底是怎么回事。

市面上回测框架一堆，装一个就能跑，但跑完不知道那堆数字怎么来的。所以从零写一个——只依赖 pandas 和 matplotlib，不用任何量化回测库。

代码和文章一起写，每个阶段跑通一个模块，再写一篇总结。

## 现在有什么

- **数据层**：akshare 下载 A 股日线，东方财富接口失败时自动切新浪/腾讯；清洗、停牌标记、前复权
- **策略层**：双均线、MACD、RSI、布林带，统一基类接口；另有纯 Python 增量指标（实盘/模拟盘用）
- **单标的回测**：Broker（佣金万 2.5 + 最低 5 元 + 千一印花税 + 滑点）、Portfolio、T+1、止损止盈
- **多标的组合回测**：多个标的对齐、目标权重、定期调仓、先卖后买、等权/动量分配、等权基准对比
- **成交约束**：涨停不能买、跌停不能卖、停牌不成交、单笔不超过当日成交额的一定比例；约束触发次数单独统计
- **绩效分析**：年化收益、波动率、夏普、最大回撤及持续期、Calmar、盈亏比；净值/回撤/权重/相关矩阵图
- **参数优化**：网格搜索、滚动优化（walk-forward）
- **因子 demo**：Fama-French 三因子回归、因子暴露、横截面验证
- **因子研究**：前向收益、逐日横截面 IC / RankIC、ICIR 与 t 值、分层（quantile）回测、横截面 z-score、多因子合成、IC/分层图
- **因子中性化**：每日缩尾（分位数 / MAD）、行业去均值、市值回归取残差（多元残差化）、中性化前后 IC 与暴露对比
- **股票池**：全市场快照 → 过滤 ST/北交所 → 按流通市值取前 N → 补行业分类，结果落盘复用；东财快照限流时自动降级到新浪行情，按当日成交额选池

## 安装与运行

```bash
pip install -r requirements.txt

# 单只股票
python main.py fetch 000001
python main.py backtest ma_cross 000001 -p fast=5 -p slow=20 --analyze

# 批量下载
python main.py fetch-all 000001,600519,000858,300750,601318,600036 --start 20190101 --end 20241231

# 多标的组合回测（默认开启涨跌停 / 停牌 / 流动性约束）
python main.py portfolio \
    --symbols 000001,600519,000858,300750,601318,600036,000651,002415 \
    --strategy ma_cross -p fast=10 -p slow=30 \
    --alloc equal --rebalance 5 --start 20190101 --end 20241231 --analyze

# 关闭约束做对照
python main.py portfolio --symbols ... --no-limit --max-participation 0

# 选股票池（东财限流时自动降级到新浪成交额排序）
python main.py universe --top 20 --fetch --start 20190101 --end 20241231

# 因子 IC 分析 + 分层回测
python main.py factor \
    --symbols 000001,600519,000858,300750,601318,600036,000651,002415 \
    --period 5 --quantiles 5 --analyze
```

组合层有两个分配规则：

- `--alloc equal`：信号为多头（策略返回 1）的标的等权
- `--alloc momentum --top 3`：在多头标的中按过去 20 日涨幅排序，取前 3 只

### 成交约束

回测里"想买"和"能买到"是两件事。组合引擎现在检查三件事：

- **涨停不能买、跌停不能卖**：用当日收盘相对前收的涨跌幅判断，主板 ±10%、创业板/科创板 ±20%、北交所 ±30%；
- **停牌不成交**：日期对齐默认用并集，某只股票当天没有行情就视为停牌，买单和卖单都会被拦下；停牌期间沿用前收估值；
- **流动性上限**：单笔最多吃掉当日成交额的 `--max-participation`（默认 10%），避免小盘股上出现不现实的成交量。

19 只 2019—2024 的真实数据（双均线 5/20，5 日调仓）上做了一次对照：

```
                          开启约束        关闭约束
总收益率                   +19.37%        +13.74%
年化收益                    +4.21%         +3.04%
最大回撤                   -51.25%        -53.80%
被拦下的交易        涨跌停 36 次          —
```

这组样本里，涨跌停约束拦掉了 36 次追涨停/杀跌停的成交，结果反而略微好一点；换一组股票或策略，方向可能反过来。重点不是这个数字，而是回测现在会如实报告"有多少笔交易没做成"。

## 因子研究

`factor` 命令做的是"判断一个指标有没有预测能力"，而不是直接回测策略：

```
因子                mean IC    ICIR      t值     胜率    样本
--------------------------------------------------------------
momentum_20       -0.0001  -0.000   -0.01  48.57%   1431
reversal_5         0.0126   0.029    1.11  50.35%   1446
vol_20             0.0029   0.007    0.27  48.92%   1431
vol_ratio         -0.0151  -0.035   -1.34  47.49%   1432
turnover_20       -0.0020  -0.005   -0.21  48.95%   1432
```

- `mean IC`：每个交易日对"因子值"和"未来 N 日收益"做一次横截面相关，再取均值
- `ICIR`：mean IC / IC 标准差，衡量稳定性
- 分层：按因子值把股票分成 5 组，看每组未来收益是否单调；Q5 - Q1 就是多空价差

内置因子：`momentum_20`、`reversal_5`、`vol_20`、`vol_ratio`、`turnover_20`。

上面的数字来自仓库里缓存的 8 只股票——横截面只有 8 个样本，IC 的统计意义很弱，这组结果只能说明流程跑通了，不代表这些因子在 A 股无效。要做真正的因子研究，至少需要几百只股票、剔除 ST/新股/停牌。

## 因子中性化

`--neutralize industry,size` 会先缩尾，再对行业去均值，然后对 ln(流通市值) 做逐日横截面回归取残差，最后重新 z-score。市值不用快照接口里的"当前市值"（那是未来信息），而是由当天的成交额和换手率反推：`流通市值 ≈ 成交额 / 换手率`。

8 只股票上的实测（2019—2024，持有期 5 日）：

```
因子                   原始 IC     中性 IC        原始市值暴露        中性市值暴露
--------------------------------------------------------------
momentum_20        -0.0001   -0.0032            4%            0%
reversal_5          0.0126    0.0073           -3%           -0%
vol_20              0.0029    0.0087            6%            0%
vol_ratio          -0.0151   -0.0108            1%           -0%
turnover_20        -0.0020   -0.0022          -62%           -0%
```

`turnover_20`（20 日平均换手率）和市值有 -62% 的相关——这个因子基本是在赌小盘股，中性化之后这部分暴露被干净地拿掉了。其他几个因子在 8 只股票的样本里本来就没有多少市值暴露，变化不大。

行业中性化对只有一只股票的行业不起作用（减完均值恒等于 0，等于把信息抹掉），所以行业内样本数小于 2 的组会保持原值。

## 一些限制

- 成交模型是"当日收盘信号、当日收盘成交"，严格回测应该次日开盘成交
- 组合回测中一手（100 股）无法拆分，资金小的时候高价股会买不满，剩余现金留在账上
- 涨跌停幅度按代码推断，无法识别 ST 股的 ±5%；停牌是否可见取决于数据源是否保留停牌日
- 没有做分红再投资；流动性约束用的是当日成交额，盘口深度和冲击成本没有建模
- 因子研究的样本仍然偏小；中性化提供了工具，但没有处理幸存者偏差
- 股票池按"当前"流通市值排序，回看历史时天然带着幸存者偏差（今天还在的、还大的股票）
- 数据源是公开接口，历史数据可能因复权基准变化而微调
