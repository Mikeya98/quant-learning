# quant-learning

写嵌入式 C 写了好几年，最近想搞清楚量化交易到底是怎么回事。

市面上回测框架一堆，装一个就能跑，但跑完不知道那堆数字怎么来的。所以从零写一个——只依赖 pandas 和 matplotlib，不用任何量化回测库。

代码和文章一起写，每个阶段跑通一个模块，再写一篇总结。

## 现在有什么

- **数据层**：akshare 下载 A 股日线，东方财富接口失败时自动切新浪/腾讯；清洗、停牌标记、前复权
- **策略层**：双均线、MACD、RSI、布林带，统一基类接口；另有纯 Python 增量指标（实盘/模拟盘用）
- **单标的回测**：Broker（佣金万 2.5 + 最低 5 元 + 卖出千一印花税 + 双向万分之 0.1 过户费 + 滑点）、Portfolio、T+1、止损止盈
- **多标的组合回测**：多个标的对齐、目标权重、定期调仓、先卖后买、等权/动量分配、等权基准对比
- **成交约束**：涨停不能买、跌停不能卖（涨跌停价按交易所规则取整到 0.01 元）、停牌不成交、单笔不超过成交额的一定比例（次日开盘模式用前一日成交额，避免未来信息）；约束触发次数单独统计
- **绩效分析**：年化收益、波动率、夏普、最大回撤及持续期、Calmar、盈亏比；相对等权基准的 beta、Jensen alpha、跟踪误差、信息比率；净值/回撤/权重/相关矩阵图
- **收益归因**：个券贡献（前一日权重 × 当日涨幅）、残差（费用/成交时点）、Brinson 配置/选择/交互三效应；组合等权基准的恒等式自检，`--attribution` 直接输出
- **因子归因**：从回测数据里自建 MKT / SMB / MOM 三因子（全池等权、小减大市值、过去 N 日赢家减输家），把组合日收益回归到因子上，给出风格暴露、t 值、R² 和收益分解。分组只用 t-1 信息，避免未来函数。`--factor-attribution` 输出报告；带截距的样本内回归残差总和恒为 0，所以另做 `--factor-oos 0.5` 样本外分解（前半段估 beta、后半段算残差），才能真正看到选股贡献
- **交易成本拆分**：每笔成交拆成佣金、印花税、过户费（显性，直接扣现金）和滑点（隐性，体现在成交价里），按方向/标的汇总并换算成 bps；`--costs` 输出报告。显性成本和滑点分开列，避免把"少赚的钱"和"实际交的钱"加成一个数
- **平方根冲击成本**：`--slip-model sqrt` 在固定滑点之外叠加 `impact_coeff × sqrt(参与率)`，参与率 = 本笔成交额 / 当日成交额；参与率随股数变化，`calc_shares` 迭代收敛到含冲击的真实预算。trades 表记录每笔 `participation` 和 `impact_bps`，`--costs` 增加"冲击成本"区块（平均/最高参与率、冲击占滑点比例）。成交额缺失时退化成固定滑点
- **参数优化**：网格搜索、滚动优化（walk-forward）
- **因子 demo**：Fama-French 三因子回归、因子暴露、横截面验证
- **因子研究**：前向收益、逐日横截面 IC / RankIC、ICIR 与 t 值、分层（quantile）回测、横截面 z-score、多因子合成、IC/分层图
- **因子中性化**：每日缩尾（分位数 / MAD）、行业去均值、市值回归取残差（多元残差化）、中性化前后 IC 与暴露对比
- **股票池**：全市场快照 → 过滤 ST/北交所 → 按流通市值取前 N → 补行业分类，结果落盘复用；东财快照限流时自动降级到新浪行情，按当日成交额选池
- **多因子选股组合**：把因子研究接进组合引擎——每个调仓日横截面打分、取前 N 只等权持有，中间不再换股。分数支持等权合成和**滚动 IC 加权**：只用 `t-ic_period` 以前已知的 IC 给因子加权重，IC 为负的因子自动反向使用，避免"动量在 A 股某些年份失效时把组合带偏"。`factor-portfolio` 命令同时输出合成分数与单因子 IC 诊断、持仓换手统计，再用同一套涨跌停/停牌/流动性约束做回测
- **因子正交化与中性化预处理**：合成之前可以按 `--factors` 的顺序逐日做横截面正交化——后面的因子对前面已经取过残差的因子回归，只保留别人没解释掉的部分，避免相关因子重复计权。也可以接入缩尾、行业去均值、市值回归残差（`--winsorize / --neutralize industry,size`），IC 加权时在预处理后的因子上估计 IC，保证"估计用的因子"和"打分的因子"是同一个。实测 25 只 2019-2024：原始动量/反转的相关是 -0.46，正交化后降到 0；波动率的市值暴露 +0.43，市值中性化后降到 0
- **IC 参数 walk-forward 调参**：`factor-tune` 把时间轴切成训练/测试折，每折只在训练段上按 IC/ICIR/t 从网格里挑 `ic_period` 和 `ic_window`，原样用到测试段，再和固定参数逐折对比。实测 25 只 2019-2024，训练段 IC 全在 +0.02~+0.05，样本外平均 -0.039（固定参数 -0.009），逐折胜出 1/3——在这组数据上调参没有打过固定参数，文章里把原因和切法都写清楚了
- **IC 期限敏感性**：`factor-sensitivity` 同时扫两个期限——信号期限（因子回看多少天）和评估期限（IC 对未来多少天收益算），输出两张表：因子 × 评估期限的平均 RankIC、momentum 的信号期限 × 评估期限矩阵，并给出分段稳定性。重叠的前向收益会让普通 t 值虚高，所以每个 horizon 都用 lag=H-1 的 Newey-West 修正后再看显著性。实测 25 只 2019-2024：`vol_20` 在 20 日收益上普通 t=-5.39，修正后只剩 -1.51；`momentum_20` 的 5 日 t 从 -2.86 收缩到 -1.68。信号期限扫过去最优值在 5/10/20/40/60 之间跳，没有稳定窗口
- **IC 显著性推断**：`factor-inference` 用 block bootstrap（circular / stationary，块长取评估期限）和 Newey-West 对照。两者在这组数据上算出的 t 值几乎相同（`vol_20` 20 日都是 -1.51），bootstrap 另外给出 95% 置信区间：`momentum_20` 只有 1 日和 3 日的区间完全在 0 以下，5 日以上跨 0。区间同时给百分位和 BCa 两种，BCa 用 z0 修中位数偏差、刀切加速度修偏度；覆盖率模拟显示它补不了块长不足造成的方差低估
- **块长自动选择**：`factor-blocklength` 用 Politis-White (2004) 从 IC 序列自身的自相关估最优块长——隐含假设检验找 m_hat、平顶核估 G、代入 `(2G²/(cσ⁴)·n)^(1/3)`，分别给平稳/环形 bootstrap 的块长。`factor-inference --block-method pw-sb/pw-cb` 直接改用这个块长。实测 25 只 2019-2024：1 日 horizon 的 ρ1 只有 -0.05，块长选 1；20 日 horizon 的 ρ1 到 0.72~0.93，块长顶到上限 113。块长从 horizon 换成 PW 后，多日 horizon 的 SE 大 1%~19%，显著性的结论不变（仍全部跨 0）；覆盖率模拟显示块长 1 在 ρ=0.7 时 95% 区间只覆盖 56%，PW 把覆盖率拉回 92%

# 批量下载
python main.py fetch-all 000001,600519,000858,300750,601318,600036 --start 20190101 --end 20241231

# 多标的组合回测（默认开启涨跌停 / 停牌 / 流动性约束）
python main.py portfolio \
    --symbols 000001,600519,000858,300750,601318,600036,000651,002415 \
    --strategy ma_cross -p fast=10 -p slow=30 \
    --alloc equal --rebalance 5 --start 20190101 --end 20241231 --analyze

python main.py portfolio --symbols 000001,600519,000858,300750 \
    --strategy ma_cross -p fast=5 -p slow=20 --rebalance 5 --attribution

# 加 --factor-attribution 打印因子归因（MKT/SMB/MOM）
#   --factor-oos 0.5 做样本外分解；--factor-mom 20 调动量回看天数
python main.py portfolio \
    --symbols 000001,600519,000858,300750,601318,600036 \
    --strategy ma_cross -p fast=5 -p slow=20 --rebalance 5 \
    --factor-attribution --factor-oos 0.5

# 加 --costs 打印交易成本拆分（佣金/印花税/过户费/滑点）
python main.py portfolio --symbols 000001,600519,000858,300750 \
    --strategy ma_cross -p fast=5 -p slow=20 --rebalance 5 --costs

# 平方根冲击成本：资金量越大、参与率越高，冲击越明显
python main.py portfolio --symbols ... --capital 10000000 \
    --slip-model sqrt --impact-coeff 0.01 --max-impact 0.05 --costs

# 次日开盘成交（更接近实盘），并指定 ST 名单
python main.py portfolio --symbols ... --exec next_open --st-file st.txt

# 关闭约束做对照
python main.py portfolio --symbols ... --no-limit --max-participation 0

# 选股票池（东财限流时自动降级到新浪成交额排序）
python main.py universe --top 20 --fetch --start 20190101 --end 20241231

# 因子 IC 分析 + 分层回测
python main.py factor \
    --symbols 000001,600519,000858,300750,601318,600036,000651,002415 \
    --period 5 --quantiles 5 --analyze

# 多因子选股组合：每 10 个交易日按合成分数取前 5 只，次日开盘调仓
python main.py factor-portfolio \
    --symbols 000001,000651,000858,300750,600519,601318 \
    --factors momentum_20,reversal_5,vol_20 \
    --top 5 --rebalance 10 --exec next_open --start 20190101 --end 20241231

# 滚动 IC 加权：因子方向由历史 IC 决定，负 IC 自动反向
python main.py factor-portfolio \
    --symbols 000001,000651,000858,300750,600519,601318 \
    --factors momentum_20,reversal_5,vol_20 \
    --weight-mode ic --ic-window 60 --top 5 --rebalance 10

# 预处理：缩尾 + 市值中性化 + 按 factors 顺序正交化，再做 IC 加权
python main.py factor-portfolio \
    --symbols ... --weight-mode ic --ic-window 60 \
    --winsorize --neutralize size --orthogonalize \
    --top 5 --rebalance 10

组合层有两个分配规则：

- `--alloc equal`：信号为多头（策略返回 1）的标的等权
- `--alloc momentum --top 3`：在多头标的中按过去 20 日涨幅排序，取前 3 只

### 成交约束

回测里"想买"和"能买到"是两件事。组合引擎现在检查三件事：

- **涨停不能买、跌停不能卖**：收盘成交看收盘价相对前收，次日开盘成交看开盘价相对前收；主板 ±10%、创业板/科创板 ±20%、北交所 ±30%，主板 ST 用 `--st-file` 指定后按 ±5%；
- **停牌不成交**：日期对齐默认用并集，某只股票当天没有行情就视为停牌，买单和卖单都会被拦下；停牌期间沿用前收估值；
- **流动性上限**：单笔最多吃掉当日成交额的 `--max-participation`（默认 10%），避免小盘股上出现不现实的成交量。

19 只 2019—2024 的真实数据（双均线 5/20，5 日调仓）上做了一次对照：

```
                          开启约束        关闭约束
总收益率                   +19.37%        +13.74%
年化收益                    +4.21%         +3.04%
最大回撤                   -51.25%        -53.80%
被拦下的交易        涨跌停 36 次          —
```

这组样本里，涨跌停约束拦掉了 36 次追涨停/杀跌停的成交，结果反而略微好一点；换一组股票或策略，方向可能反过来。重点不是这个数字，而是回测现在会如实报告"有多少笔交易没做成"。

### 次日开盘成交

`--exec next_open` 把信号日和成交日拆开：第 i-1 天的收盘信号，第 i 天开盘成交。涨跌停判断也跟着换成"开盘价相对前收"，避免用收盘价判断、用开盘价成交的错位。

25 只股票、双均线 5/20、5 日调仓的对照：

```
                          当日收盘        次日开盘
总收益率                   +14.94%         -3.50%
年化收益                    +3.30%         -0.83%
最大回撤                   -50.31%        -58.85%
涨跌停拦截                   43 次          11 次
```

收盘成交多出来的 18 个百分点，主要是"用已经知道的收盘价下单"带来的高估；隔夜跳空则让回撤更深。涨跌停拦截次数下降，是因为判断口径从收盘涨跌幅换成了开盘跳空，两者回答的不是同一个问题。

### 冲击成本

固定滑点假设"每笔都是 0.1%"，不管买多少。真实市场里，订单越大，越会把价格推向不利方向。`--slip-model sqrt` 用平方根模型补上这一段：

```
冲击 = impact_coeff × sqrt(参与率)
参与率 = 本笔成交额 / 当日成交额
```

同样 25 只股票、双均线 5/20、5 日调仓，把资金从 10 万放大到 1000 万：

```
                          固定滑点        平方根冲击
总收益率                    -4.71%          -9.91%
年化收益                    -1.12%          -2.40%
最大回撤                   -52.74%         -54.27%
滑点成本                  10.0 bps         12.7 bps
其中冲击成本               0.0 bps          2.7 bps
冲击占滑点比例                0%            21.5%
最高参与率                  3.88%           3.84%
```

10 万资金时参与率最高 0.04%，冲击几乎可以忽略；1000 万时平均参与率 0.06%、最高接近 4%，冲击成本占到滑点的两成，总收益被多拖走 5 个百分点。这就是为什么小资金回测出来的策略，放大资金后往往跑不出来。

## 因子研究

`factor` 命令做的是"判断一个指标有没有预测能力"，而不是直接回测策略：

```
因子                mean IC    ICIR      t值     胜率    样本
--------------------------------------------------------------
momentum_20       -0.0001  -0.000   -0.01  48.57%   1431
reversal_5         0.0126   0.029    1.11  50.35%   1446
vol_20             0.0029   0.007    0.27  48.92%   1431
vol_ratio         -0.0151  -0.035   -1.34  47.49%   1432
turnover_20       -0.0020  -0.005   -0.21  48.95%   1432
```

- `mean IC`：每个交易日对"因子值"和"未来 N 日收益"做一次横截面相关，再取均值
- `ICIR`：mean IC / IC 标准差，衡量稳定性
- 分层：按因子值把股票分成 5 组，看每组未来收益是否单调；Q5 - Q1 就是多空价差

内置因子：`momentum_20`、`reversal_5`、`vol_20`、`vol_ratio`、`turnover_20`。

上面的数字来自仓库里缓存的 8 只股票——横截面只有 8 个样本，IC 的统计意义很弱，这组结果只能说明流程跑通了，不代表这些因子在 A 股无效。要做真正的因子研究，至少需要几百只股票、剔除 ST/新股/停牌。

## 因子中性化

`--neutralize industry,size` 会先缩尾，再对行业去均值，然后对 ln(流通市值) 做逐日横截面回归取残差，最后重新 z-score。市值不用快照接口里的"当前市值"（那是未来信息），而是由当天的成交额和换手率反推：`流通市值 ≈ 成交额 / 换手率`。

8 只股票上的实测（2019—2024，持有期 5 日）：

```
因子                   原始 IC     中性 IC        原始市值暴露        中性市值暴露
--------------------------------------------------------------
momentum_20        -0.0001   -0.0032            4%            0%
reversal_5          0.0126    0.0073           -3%           -0%
vol_20              0.0029    0.0087            6%            0%
vol_ratio          -0.0151   -0.0108            1%           -0%
turnover_20        -0.0020   -0.0022          -62%           -0%
```

`turnover_20`（20 日平均换手率）和市值有 -62% 的相关——这个因子基本是在赌小盘股，中性化之后这部分暴露被干净地拿掉了。其他几个因子在 8 只股票的样本里本来就没有多少市值暴露，变化不大。

行业中性化对只有一只股票的行业不起作用（减完均值恒等于 0，等于把信息抹掉），所以行业内样本数小于 2 的组会保持原值。

## 因子参数调优

滚动 IC 加权有两个超参数：`ic_period`（估计 IC 用多少天的前向收益）和 `ic_window`（过去多少个 IC 求平均）。在整段历史上网格搜索再汇报结果，是典型的过拟合——参数是看着答案选的。

`factor-tune` 改成 walk-forward：把时间轴切成若干"训练段 → 测试段"，每折只在训练段上挑参数，原样用到紧挨着的测试段，最后和固定参数（20/60）逐折对比。

```bash
python main.py factor-tune --symbols 000001,000651,... --folds 3
```

25 只股票、2019—2024、16 组参数（ic_period 5/10/20/40 × ic_window 20/40/60/120）的实测：

```
  折  训练区间                 测试区间                 参数    训练IC    测试IC    基线IC
   0  2019-01-02~2021-12-29  2021-12-30~2022-12-29   20/20  +0.0501  -0.0736  +0.0034
   1  2019-01-02~2022-12-29  2022-12-30~2023-12-29   5/120  +0.0248  +0.0034  -0.0333
   2  2019-01-02~2023-12-29  2024-01-02~2024-12-31   5/120  +0.0204  -0.0477  +0.0017

  样本外平均 IC: -0.0393    固定参数: -0.0094    平均提升: -0.0299
  逐折胜出: 33% (1/3)       正 IC 折数: 1/3
```

训练段 IC 全是正的（+0.02 ~ +0.05），换到测试段一半以上变负。换成 ICIR 标准挑参数，三折选出来的还是同样两组参数；改成 4 折 rolling 重新切，结论一样（平均 IC -0.0175 vs 基线 -0.0095，胜率 25%）。这组数据上，"逐折调参"没有打过固定参数，原因很直接：最优窗口在折与折之间跳变（20/20 和 5/120 反复横跳），说明训练段里的优势本身是噪声。

代码在 `src/strategy/ic_tuning.py`，支持 expanding/rolling 两种训练窗口、IC/ICIR/t 三种挑选标准，评测只看测试段。

## IC 期限敏感性

因子研究的结论对两个期限很敏感：信号期限（因子回看多少天）和评估期限（IC 对未来多少天收益算）。`factor-sensitivity` 把两者拆开扫：

```bash
python main.py factor-sensitivity --symbols 000001,000651,... \
    --horizons 1,3,5,10,20 --lookbacks 5,10,20,40,60
```

25 只股票、2019—2024 的实测：

```
  1) 因子 × 评估期限：平均 RankIC
                            1d       3d       5d      10d      20d
     momentum_20       -0.0169  -0.0244  -0.0237  -0.0173  -0.0178
     reversal_5         0.0243   0.0147   0.0135  -0.0005   0.0189
     vol_20             0.0072  -0.0039  -0.0079  -0.0324  -0.0552

  Newey-West t（lag = horizon - 1；括号内是未修正 t）
     momentum_20         -2.00(-2.00)    -2.12(-2.95)    -1.68(-2.86)    -0.94(-2.15)    -0.72(-2.20)
     reversal_5           3.04( 3.04)     1.44( 1.90)     1.12( 1.75)    -0.04(-0.06)     1.26( 2.35)
     vol_20               0.70( 0.70)    -0.27(-0.39)    -0.44(-0.79)    -1.31(-3.30)    -1.51(-5.39)
```

评估期越长，相邻样本共享的价格区间越多，IC 序列的正自相关越强。普通 t 值把 250 个重叠样本当成 250 个独立样本，`vol_20` 在 20 日收益上能算出 -5.39；用 lag=19 的 Newey-West 修正后只剩 -1.51，按 2 倍标准误看已经不显著。`reversal_5` 在 20 日上也是同样的故事：未修正 2.35，修正后 1.26。

信号期限 × 评估期限的矩阵则显示另一件事——最优 lookback 并不稳定：

```
        1d       3d       5d      10d      20d
  5d  -0.0243  -0.0147  -0.0135   0.0005  -0.0189
 10d  -0.0137  -0.0074  -0.0008  -0.0049  -0.0204
 20d  -0.0169  -0.0244  -0.0237  -0.0173  -0.0178
 40d  -0.0124  -0.0181  -0.0192  -0.0118  -0.0235
 60d  -0.0087  -0.0138  -0.0205  -0.0095  -0.0057
```

每列的最优 lookback 都不一样，说明这组数据上不存在"一个期限通吃"的动量因子。最后的分段稳定性表把样本切成 4 段：`momentum_20` 四段全为负（100% 同号），`reversal_5` 和 `vol_20` 都是 75%，中间都有一段方向翻转——全样本 IC 再高，也不能忽略这个。

代码在 `src/analysis/ic_sensitivity.py`，Newey-West 使用 Bartlett 核，lag 默认取评估期限减一。

## IC 显著性：Newey-West vs block bootstrap

Newey-West 是解析近似，lag 要自己选。`factor-inference` 加了一个不依赖解析公式的对照：把 IC 序列按块重采样（circular 或 stationary），块长取评估期限，从重采样均值里直接算标准误、t 值和百分位置信区间。

```bash
python main.py factor-inference --symbols 000001,000651,... \
    --horizons 1,3,5,10,20 --n-boot 2000
```

25 只股票、2019—2024：

```
  因子              h   mean_IC  t_naive    t_NW   t_boot  boot_SE                95% CI
  momentum_20     1   -0.0169    -2.00   -2.00    -2.01   0.0084     [-0.0341,-0.0008]
  momentum_20     3   -0.0244    -2.95   -2.12    -2.06   0.0119     [-0.0468,-0.0007]
  momentum_20     5   -0.0237    -2.86   -1.68    -1.67   0.0142     [-0.0515,+0.0048]
  momentum_20    10   -0.0173    -2.15   -0.94    -0.91   0.0190     [-0.0537,+0.0199]
  momentum_20    20   -0.0178    -2.20   -0.72    -0.73   0.0242     [-0.0648,+0.0287]
  reversal_5      1    0.0243     3.04    3.04     3.06   0.0079     [+0.0076,+0.0398]
  reversal_5      5    0.0135     1.75    1.12     1.12   0.0121     [-0.0108,+0.0356]
  vol_20         20   -0.0552    -5.39   -1.51    -1.51   0.0366     [-0.1275,+0.0151]
```

两种修正的 t 值几乎一样（`vol_20` 20 日都是 -1.51，`momentum_20` 5 日 -1.68 vs -1.67），说明在这里 Newey-West 的 Bartlett 核和块重采样估出来的长期方差一致。差别在于 bootstrap 还给了置信区间：`momentum_20` 只有 1 日、3 日的 95% CI 完全在 0 以下，5 日以上都跨 0。

代码在 `src/analysis/ic_inference.py`，circular 按固定块长重采样，stationary 用几何分布的块长。bootstrap 修的是时间自相关，修不了样本量；25 只股票的横截面仍然太小。

## 块长怎么选：Politis-White 自动块长

上一篇的块长取评估期限，是个假设。`factor-blocklength` 把它交给数据：算样本自相关，找连续不显著的起点 m_hat，用平顶核估 `G = Σ h(k/M)|k|γ(k)`，再代入 `b_opt = (2G²/(cσ⁴)·n)^(1/3)`。平稳 bootstrap 取 c=2，环形取 c=4/3（PW 2009 修正）。

```bash
python main.py factor-blocklength --symbols 000001,000651,... \
    --horizons 1,3,5,10,20 --curve --simulate
python main.py factor-inference --symbols 000001,000651,... \
    --horizons 1,5,20 --block-method pw-sb
```

25 只股票、2019—2024 的块长表：

```
  因子              h     n m_hat    M   b_SB   b_CB    rho1    rho5   rho20
  momentum_20     1  1435     0    0    1.0    1.0  -0.053  -0.037  -0.004
  momentum_20     5  1431     6   12   11.9   13.6   0.701  -0.107   0.028
  momentum_20    20  1416    12   24  113.0  113.0   0.876   0.514  -0.047
  reversal_5      1  1450     0    0    1.0    1.0  -0.039   0.021  -0.001
  reversal_5     20  1431     4    8   35.0   40.1   0.720  -0.038   0.002
  vol_20          1  1435     0    0    1.0    1.0  -0.029   0.011   0.029
  vol_20         20  1416    18   36  113.0  113.0   0.933   0.702   0.030
```

1 日 horizon 基本是白噪声（ρ1 约 -0.05），块长 1；多日 horizon 的自相关很强，20 日 horizon 顶到 b_max=113。块长从 horizon 换成 PW 后，`reversal_5` 5 日的 t 从 1.12 收到 0.96、`vol_20` 5 日从 -0.44 收到 -0.37，其余变化更小，结论不变（置信区间跨 0）。

覆盖率模拟用已知均值为 0 的 AR(1) 检验区间是否可信：ρ=0.7 时块长 1 的 95% 区间只覆盖 56%，PW 自适应块长覆盖 92%，和 Newey-West 相当。剩下的 3 个百分点是百分位 bootstrap 的有限样本欠覆盖。

代码在 `src/analysis/block_length.py`。PW 也有边界：样本短时块长被 b_max 截断，负自相关会让块长对 horizon 不单调，这两点在文章里都留了记录。

## BCa：百分位区间修不了的东西

块长选对之后，区间本身还有一层偏差。百分位区间直接把重采样分布的 2.5%/97.5% 分位当成区间，隐含假设 bootstrap 分布的中心落在样本统计量上、而且分布对称。这两条在有限样本里都不一定成立，BCa 用两个量去修：

- `z0 = Φ⁻¹(P(θ* < θ̂))`：中位数偏差。重采样分布整体偏到一边时，区间跟着平移；
- 刀切加速度 `a = Σd³ / (6(Σd²)^1.5)`，`d_i = θ̄_jack − θ_(i)`：样本偏度带来的方差不对称，区间两端按它拉伸。均值的刀切值有闭式解 `θ_(i) = (nθ̂ − x_i)/(n−1)`，不用真重算 n 次。

`factor-inference` 现在同时打印两种区间。25 只股票、2019—2024，块长用 PW 环形：

```
  因子              h   mean_IC  t_naive    t_NW     L   t_boot  boot_SE               CI(百分位)               CI(BCa)
  momentum_20     1   -0.0169    -2.00   -2.00     1    -2.01   0.0084     [-0.0341,-0.0008]     [-0.0344,-0.0012]
  momentum_20     5   -0.0237    -2.86   -1.68    14    -1.56   0.0152     [-0.0524,+0.0070]     [-0.0543,+0.0051]
  momentum_20    20   -0.0178    -2.20   -0.72   113    -0.70   0.0252     [-0.0683,+0.0309]     [-0.0745,+0.0265]
  reversal_5      1    0.0243     3.04    3.04     1     3.06   0.0079     [+0.0076,+0.0398]     [+0.0081,+0.0404]
  reversal_5     20    0.0189     2.35    1.26    40     1.29   0.0146     [-0.0110,+0.0467]     [-0.0114,+0.0461]
  vol_20         20   -0.0552    -5.39   -1.51   113    -1.45   0.0380     [-0.1304,+0.0167]     [-0.1288,+0.0199]
```

块长 1 的时候两种区间几乎一样（对称、偏差小），20 日、块长 113 的时候 BCa 通常更宽一点：`momentum_20` 20 日的下界从 -0.0683 拉到 -0.0745。方向没有变，所有多日 horizon 的区间还是跨 0。

覆盖率模拟里 BCa 的成绩单并不好看。ρ=0.7 的 AR(1)，真均值 0：

```
  方法               平均块长      百分位       BCa
  L=1                1.0    55.0%      55.8%
  L=5                5.0    80.8%      79.2%
  L=20              20.0    87.5%      88.3%
  PW 自适应            48.5    89.2%      88.3%
  普通 t               1.0    57.5%          -
  Newey-West        48.5    87.5%          -
```

块长 1 时覆盖率从 55.0% 只挪到 55.8%，块长 5 反而降了 1.6 个百分点。原因不复杂：AR(1) 的样本均值分布本身接近正态，BCa 要修的两个偏差都很小；这里 40 个百分点的缺口来自"块长没覆盖住自相关导致 SE 本身偏小"，不是分位数算错了。区间修正替代不了块长选择——先把 L 从 1 加到 20，覆盖率就从 55% 到 87.5%，BCa 在这上面加不动。

代码在 `src/analysis/ic_inference.py`，`bca_interval` 对任意统计量的重采样结果都能用，只是刀切那一步这里只实现了均值（有闭式解）。

## 一些限制

- 默认成交模型是"当日收盘信号、当日收盘成交"；`--exec next_open` 已支持次日开盘，但没有建模集合竞价和开盘瞬间流动性
- 组合回测中一手（100 股）无法拆分，资金小的时候高价股会买不满，剩余现金留在账上
- ST 股需要 `--st-file` 提供名单，且名单是当前状态，不能反映历史戴帽/摘帽；停牌是否可见取决于数据源是否保留停牌日
- 没有做分红再投资；流动性约束用的是当日成交额，盘口深度和冲击成本没有建模
- 因子研究的样本仍然偏小；中性化提供了工具，但没有处理幸存者偏差
- 股票池按"当前"流通市值排序，回看历史时天然带着幸存者偏差（今天还在的、还大的股票）
- 数据源是公开接口，历史数据可能因复权基准变化而微调
