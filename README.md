# quant-learning

写嵌入式 C 写了好几年，最近想搞清楚量化交易到底是怎么回事。

市面上回测框架一堆，装一个就能跑，但跑完不知道那堆数字怎么来的。所以从零写一个——只依赖 pandas 和 matplotlib，不用任何量化回测库。

代码和文章一起写，每个阶段跑通一个模块，再写一篇总结。

## 现在有什么

- **数据层**：akshare 下载 A 股日线，东方财富接口失败时自动切新浪/腾讯；清洗、停牌标记、前复权
- **策略层**：双均线、MACD、RSI、布林带，统一基类接口；另有纯 Python 增量指标（实盘/模拟盘用）
- **单标的回测**：Broker（佣金万 2.5 + 最低 5 元 + 千一印花税 + 滑点）、Portfolio、T+1、止损止盈
- **多标的组合回测**：多个标的对齐、目标权重、定期调仓、先卖后买、等权/动量分配、等权基准对比
- **绩效分析**：年化收益、波动率、夏普、最大回撤及持续期、Calmar、盈亏比；净值/回撤/权重/相关矩阵图
- **参数优化**：网格搜索、滚动优化（walk-forward）
- **因子 demo**：Fama-French 三因子回归、因子暴露、横截面验证

## 安装与运行

```bash
pip install -r requirements.txt

# 单只股票
python main.py fetch 000001
python main.py backtest ma_cross 000001 -p fast=5 -p slow=20 --analyze

# 批量下载
python main.py fetch-all 000001,600519,000858,300750,601318,600036 --start 20190101 --end 20241231

# 多标的组合回测
python main.py portfolio \
    --symbols 000001,600519,000858,300750,601318,600036,000651,002415 \
    --strategy ma_cross -p fast=10 -p slow=30 \
    --alloc equal --rebalance 5 --start 20190101 --end 20241231 --analyze
```

组合回测的输出（节选）：

```
  初始资金:       100,000.00
  最终净值:       175,859.55
  总收益率:          +75.86%
  年化收益:          +10.32%
  夏普比率:            0.30
  最大回撤:          -52.62%

  等权基准收益:     +158.40%
  超额收益:         -82.54%
  平均相关系数:       0.456

  调仓次数:   590
  成交笔数:   1065
  换手倍数:   167.37x
```

组合层有两个分配规则：

- `--alloc equal`：信号为多头（策略返回 1）的标的等权
- `--alloc momentum --top 3`：在多头标的中按过去 20 日涨幅排序，取前 3 只

## 一些限制

- 成交模型是"当日收盘信号、当日收盘成交"，严格回测应该次日开盘成交
- 组合回测中一手（100 股）无法拆分，资金小的时候高价股会买不满，剩余现金留在账上
- 没有做分红再投资、涨跌停约束、流动性约束
- 数据源是公开接口，历史数据可能因复权基准变化而微调
